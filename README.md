## How To Install?

Make sure you change the playerDebugMode registry to 1, as explained in this [video tutorial](https://youtu.be/dUXCviKRUGg). Once you have done this, follow one of the installation methods below.

### ZIP Version

1. Download and extract the `com.kureichi.discordrpc.zip` file from [Releases](https://github.com/Kuredew/adobe-discord-rpc/releases)
2. Cut or copy `com.kureichi.discordrpc` folder from extracted file to `C:\Program Files (x86)\Common Files\Adobe\CEP\extensions`
3. Done

### ZXP Version

1. Download `com.kureichi.discordrpc.zxp` file from [Releases](https://github.com/Kuredew/adobe-discord-rpc/releases)
2. Download and install **ZXP/UXP Installer** from [aescripts](https://aescripts.com/learn/post/zxp-installer)
3. Open **ZXP/UXP Installer** and open the `com.kureichi.discordrpc.zxp` file in ZXP/UXP Installer to start installing the extension.
4. Done

After that, you can open Adobe apps you want, then go to Window > extensions, you will see a new extension named `Discord RPC`. Open it and dock the panel to where you want it

> [!NOTE]  
> RPC will automatically turn on (because the default power value is true), you can turn off the RPC on the panel
